FlavorLab
A restaurant management web application that allows users to browse menus, place orders, and manage restaurant operations.

FlavorLab was developed to strengthen my full-stack development skills using JavaScript and server-side technologies.

Features:
  User registration and login
  Menu browsing
  Order management
  Restaurant database integration
  Responsive interface

  
Technologies Used:
  JavaScript
  Flask
  SQL Database
  HTML/CSS
